## 📝 Project Description
Instead of a traditional presentation, I developed an interactive **Python-based CLI Training Module and Quiz**. This program educates users on the dangers of phishing, how to identify fake emails and malicious URLs, and tests their knowledge through an interactive quiz.

## 🚀 Features
- **Educational Section:** Teaches the red flags of phishing and social engineering concepts.
- **Interactive Quiz:** A 3-question scenario-based test with immediate feedback.
- **Score Evaluation:** Grades the user based on their awareness level.
- **No external dependencies:** Runs purely on Python standard libraries.
